# Paradise Nursery - Shopping Cart Application

This project is the final project of "Developing Front-End Apps with React" (IBM).
It implements an online plant shop called **Paradise Nursery** with:

- a navigation bar (Home, Plants, Cart) shared by the Product Listing and Cart pages,
- product listing grouped into categories (Indoor Plants, Outdoor Plants, Succulents),
  at least six unique houseplants per category with thumbnail image, name and price,
- "Add to Cart" buttons that add the product, disable themselves after the product is added,
  and increment the cart icon count,
- a shopping cart page with total cart amount, per-plant total cost, quantity
  increase/decrease buttons, delete buttons, a checkout button ("Coming Soon")
  and a continue-shopping link back to the product listing.

Built with React, Redux Toolkit and react-router-dom.
